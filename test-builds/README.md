# Stage Alts test build

`stage-alts-randomauto-0.1.12.zip` contains the compiled NRO for Smash Ultimate 13.0.5, test instructions, build metadata, dependency lockfile, and the integration patch.

This is WuBoy's 0.1.12 foundation with the existing custom RandomAuto cycling and logging. The source matches integration commit `9adbfe4ef3eb721cdc1e35f265e03239b13e6bd7`. The release build and NRO validation passed; in-game testing is still required. Known randomization and loading issues are not claimed fixed.

Open the ZIP on GitHub and use **Download raw file**. Replace your existing Stage Alts NRO with the included `libstage_alts.nro`; keep only one copy of the plugin active. Follow `TESTING.txt` and return the resulting `stage-alts.log`.
